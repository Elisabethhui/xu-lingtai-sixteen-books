## 五、每本的产出规范

1. 一书一 MD：`<书名>/<书名>.md`，层级 `# 书名` → `## 卷／序／凡例` → `### 篇` → `#### 条目`。
2. 按语标明作者：徐氏【按】／他人【某某按】。
3. 插图存 `<书名>/images/`，正文以相对路径引用，位置与影印件一致。
4. 文件头注明：底本（影印件）、录入来源、已知问题。
5. 完成后更新 `PROGRESS.md` 与 `docs/问题汇总.md`。

## 六、预期风险

- 影印件为清刻本，**繁体**、可能无标点；转录须逐一比对，不得凭记忆补字。
- 模糊／缺页处标 `【缺】`，不得猜补。
- 「脉诀启悟注释」归属存疑，文件中须注明。
- 「舌鉴总论」的舌图须从影印件裁切，注意清晰度。
