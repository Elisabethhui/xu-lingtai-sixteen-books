# 底本来源清单

本清单记录 prompt 指定底本的**实际取材结果**。徐灵胎（1693—1771）诸书已成公有领域，以下影印件可合法用作底本。

## 一、总原则

1. 底本一以 prompt 指定版本为准，不因"方便"改换版本。
2. 版本有缺时，取**同版系统内最早可得的影印件**替补，并在本表标注差异。
3. 今人整理本（如华龄出版社《徐灵胎医书全集》）**只作讹字比对**，不作底本。
4. 民国三十二种石印本一律禁用。

## 六、取材动作（每单元开工前必做）

1. 下载对应影印件及分页图，存入 `sources/`（不入库）。
2. 核对牌记、序跋，确认版刻与卷次，回填上表"待补"。
3. 记录该单元所用页码范围。
4. 复核阶段逐段比对影印件，改动单字须能回溯。
