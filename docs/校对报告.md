## 三、两处系统性问题

### （一）字体：我方简体，典藏与影印件为繁体

- 我方输出（源自网络「医藏」点校本）**全部为简体**。
- 中华典藏及 Commons 影印件均为**繁体**。
- 这与「异体字尽量保留」的规则冲突，需用户裁定最终字体。

### （二）《医学源流论》底稿脱文

医藏本《医学源流论》有**整句脱落与讹字**，共 28 处实质差异。举例如下：

| 位置 | 医藏本（我方） | 典藏本 |
| --- | --- | --- |
| 自叙 | 使无一夫不被其**之近，不能兼及** | 使无一夫不被其**泽，甚者天地位而万物育，斯学者之极功也。若夫日救一人，月治数病，顾此失彼，虽数十里**之近，不能兼及 |
| 自叙 | 圣**遇**豪杰 | 圣**贤**豪杰 |
| 自叙 | 而**肉**数人疾病连年 | 而**骨肉**数人疾病连年 |
| 自叙 | **焉**伤怀 | **惄然**伤怀 |
| 自叙 | **洞**溪徐大椿 | **洄**溪徐大椿 |
| 无气存亡论 | 四十以前…；缺「而长既而壮日胜一日，何以四十以后…」一段 | 有 |

另有两处系**典藏多出**、非我方脱落：

- 四库提要（「二卷，国朝徐大椿撰……」）——非徐氏原文，本可不收。
- 和刻本日文编者注（如「注：水榻，此字左为水部旁……」）——典藏所据为 **1851 和刻本**，故有此注。

## 四、非徐灵胎案语排查

六本中，非徐氏所撰之案语**仅一处**：

- 《洄溪医案》正文「**雄按**」共 30 条，为**王孟英（王士雄）**按语。

其余「按」字均为实义（按脉、按方）或徐氏本人之语（如《医学源流论》「愚按」、《伤寒类方》「按：」）。

## 五、结论与待办

1. **六本中五本底稿可靠**（难经经释、神农本草经百种录、伤寒类方、洄溪医案、慎疾刍言）。
2. **《医学源流论》须重做**，改用更可靠底稿并逐段校影印件。
3. **字体待裁定**：简体 or 繁体。若从底本（影印件为繁体），宜出繁体。
4. 中华典藏所据版本须逐本标注（如《医学源流论》为 1851 和刻本），不得默认等同指定底本。
