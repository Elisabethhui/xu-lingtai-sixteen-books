# 徐灵胎医书十六种（整理稿）

清代徐灵胎（徐大椿，1693—1771）医书十六种的纯文本整理工程，用于个人公开仓库存储与研读。

本仓库**只收徐灵胎原文**：自序、凡例、各卷正文，以及文中徐氏本人的【按】。不收录现代译文、现代校注者按语或个人解读。

## 底本依据

| 书目 | 底本 |
| --- | --- |
| 1—6 种（生前亲定） | 清乾隆半松斋洄溪草堂原刻本 |
| 7—16 种（身后汇刻） | 清光绪刻本《徐灵胎医书十六种》 |
| 《洄溪医案》 | 咸丰七年蒋氏衍芬草堂刻本（王孟英校刊本） |

**严禁**以民国三十二种石印本为底本；该本混杂大量别家伪书。现代校注本仅可用于核对明显讹字，不得摘抄其译文与按语。

## 整理规则摘要

1. 只输出徐灵胎原文，禁止增补白话翻译、个人解读与引申发挥。
2. 第 7—16 种每篇篇首加文献考辨注释，说明系身后汇刻、非作者生前定稿。
3. 仅做两类规范化：添加现代中文句读标点；修正明显传抄、OCR 讹错文字。异体字尽量保留。
4. 标题层级：书名为一级标题，卷名/凡例/自序为二级标题，篇与小节为三级标题。
5. 徐氏「按」单独成段，段首标【按】，不与经文混排。
6. 只输出 Markdown 纯文本，不输出 PDF 与下载链接。

完整的强制规则见 [AGENTS.md](AGENTS.md)；任务台账见 [PROGRESS.md](PROGRESS.md)；分发与校验方案见 [docs/任务分发方案.md](docs/任务分发方案.md)。

## 文件头约定

每个 `.md` 文件首行为路径注释，例如：

```html
<!-- 文件路径：难经经释/难经经释_卷上.md -->
```

第 7—16 种的文件在路径注释之前，另加文献考辨注释。

## 精度声明

本仓库文本由古籍数字化流程产出，**以影印底本为唯一依据**，模型仅承担句读与讹字规范化，不承担凭记忆生成原文。任何未经影印底本核对的内容，均视为未经校验，不进入正式文本。

## 许可与引用

徐灵胎诸书成书于清代，已属公有领域。本仓库整理成果供研读参考；引用时请注明底本版本。
